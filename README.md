## Laboratorio di Simulazione Numerica 2025/2026

La repository contiene tutti gli esercizi del corso divisi per Lezione.

Per compilare un esercizio è presente un Makefile in ciascuna cartella, ma è necessario prima importare il contenuto della cartella Random contenente il codice del generatore di numeri casuali.\
Questo procedimento è necessario ovunque tranne che negli esercizi di simulazione molecolare (Lezione4, 6, 7) dove è già presente.
